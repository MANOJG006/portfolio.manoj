PROJECT 01 Embedded Systems • Robotics

Intelligent Path Detection Car

The Intelligent Path Detection Car is an ESP32-based robotic vehicle developed to detect obstacles and make intelligent movement decisions.

The system uses an ultrasonic sensor to identify obstacles in its path and determine when direction changes are required.

A servo motor supports sensor positioning, while the L298N motor driver controls the movement of the vehicle.

The system demonstrates real-time obstacle detection and autonomous path-avoidance behaviour.

This project helped me understand the practical integration of microcontrollers, sensors, actuators, and motor control.

It provided hands-on experience in embedded programming and basic autonomous robotic systems.

PROJECT 02 Academic Prototype • ESP32

Smart Voting System

The Smart Voting System is an ESP32-based electronic voting prototype developed to demonstrate digital vote submission and counting.

It uses a keypad to accept user input and an OLED display to provide information during the voting process.

RGB LEDs and a buzzer provide visual and audio feedback for user interactions.

The system includes basic vote validation and counting functionality.

This project helped me understand microcontroller-based input handling, output control, and embedded system integration.

It demonstrates how electronic components can be combined to create a simple interactive voting prototype.

Presented as an academic prototype exploring embedded voting logic and peripheral interfacing.
