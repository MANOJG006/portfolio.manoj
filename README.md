## 🚀 How to Run Locally (Node.js / MERN Stack)

Start a local server using Node / npm:
```bash
npm start
```
Or view directly in your browser by opening `index.html`.

---

## ☁️ Deploy to Vercel

```bash
git push -u origin main
```
Import `MANOJG006/portfolio.manoj` into [Vercel](https://vercel.com) for instant automatic deployment with SSL.
